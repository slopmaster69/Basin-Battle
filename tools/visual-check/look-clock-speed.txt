# real time (a whole day in a minute, the client's rate 24 minutes a second), and a still every
# 2.5 s for a minute: one an hour. Then the rules read back, which holds the morning again.
# Look for: the hour running on between stills in order, dawn to dusk to night and round to the
# morning, with no jump back or forward at a re-pin (every 10 s the server tells the client where
# the clock should be); the look's sky, sun and light following each hour; after the reload the
# morning again.
