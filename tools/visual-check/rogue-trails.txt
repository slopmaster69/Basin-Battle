# The Rogue's looks the server can't make (docs/rogue-roles.md, build plan 6: client patch 0103),
# floor markers off. Needs the client built with the whole patch series (HasActionCombat 32) and
# the add-on at 72 or later; on an older client the same run shows the server's own looks (both
# blades trailing pale on every blow, the flicker, the Defias shade), which is the fallback to
# compare against.
# Look for, with no floor marker and no word:
# - A run of both hands on a still grunt 3 yd ahead: the main hand's blow trails a pale streak on
#   the right-hand blade alone, the off hand's a deeper steel on the left-hand blade alone, and the
#   4th (the finisher) both blades, each its own colour, stronger. Watch the off-hand blade on a
#   main-hand blow: it must leave no ribbon.
# - Five perfect dodges of a grunt's blows (the small player from rogue-blades reads each wind-up
#   and dodges 0.12 sec before it lands): on each, a pale see-through copy of the Rogue's own body
#   and both blades, frozen in the dodge's pose, left where the blow fell for 0.3 sec and fading.
# - Afterimage (Quickstep's EX, the 1 key with Valor): a violet copy of the Rogue's own body and
#   gear standing where the Rogue was for 2 sec, keeping its look until near the end, and the
#   Defias body the server places there hidden the whole time; the grunt turns to the copy.
# - A second Afterimage inside the 2 sec: the first copy goes as the second appears.
# Needs a Rogue test hero: put a Rogue's name in the settings as `rogue = <name>`. Not run yet: the
